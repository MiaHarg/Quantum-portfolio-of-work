Hello! This repository is a personal project to develop skills needed in the intersection between Quantum Computing and cyber consulting. The repository will include one HNDL project, leading into a CBOM/migration audit project.

Here is the Exec Sum from the HNDL Project: 
This project utilizes Mosca’s theorem to assess how exposed mid-sized banks may be to quantum-enabled decryption threats where the assumptions for Q-day are 4 years, 8 years, and 12 years. 10 data types were inventoried, grouped into 6 categories, where each data type was given risk score based on attacker feasibility, collection interest, and impact. It was found that even in the most conservative scenario (12 years), 7/10 data types remain at risk. Additionally, Customer KYC/PII files rank as the top priority in every scenario, so the first step is to begin migrating the legacy cryptography that protects them to quantum-resistant standards.
